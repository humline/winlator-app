Based on the checked-out repository, the app already includes Turnip 26.2, Vortek 2.1, Zink 22.2.5, Gladio 1.1, per-container Vulkan/OpenGL driver selection, and Turnip controls for present mode, direct rendering, and heap size. The highest-priority next-update work is protecting user data during system updates, then benchmarking driver and performance changes on the Snapdragon 8 Elite rather than assuming one setting is best for every game.

1. Make system updates safer
Change rootfs installation from in-place replacement to a staged update: extract into a temporary location, verify required files and integrity, then switch to it only after the install succeeds.
Preserve the previous working system until the new one launches successfully; provide rollback on extraction, validation, or startup failure.
Before rootfs or Wine-prefix migrations, check free storage and offer a backup or clear recovery warning when a migration may alter container data.
Add a user-accessible export and restore flow for containers, shortcuts, environment variables, and input profiles. Make backups verifiable and avoid overwriting existing data during restore.
Add fault-injection checks for interrupted installs, insufficient storage, corrupt archives, and failed restores.
2. Improve driver updates and selection
Keep driver packages separate and versioned. Verify package integrity before installation, and keep the current driver available until the replacement passes validation.
Preserve each container’s driver configuration when updating app-level driver packages; show the active driver and version in container settings.
Test Turnip as the primary Vulkan candidate on Adreno 830, with Vortek as a selectable alternative. Retain Zink and Gladio for OpenGL paths and compatibility testing.
Review the existing Adreno-based memory heuristics for 8xx devices. Don’t force sysmem, gmem, or a heap size based only on model number without device testing.
Add a compact graphics diagnostic screen showing detected GPU/driver, Vulkan capabilities, selected wrappers, and relevant environment overrides.
3. Tune performance for Snapdragon 8 Elite
Establish repeatable before-and-after tests using the same device, game scenes, resolution, container, driver, and thermal state. Track frame-time consistency, sustained performance, and crashes—not just peak FPS.
Compare Turnip and Vortek across Vulkan workloads, and compare Zink/Gladio on OpenGL workloads. Test available present modes per workload; keep settings configurable rather than imposing one global “fastest” mode.
Benchmark Box64 presets and CPU-core assignments. Prefer conservative defaults, and expose experimental tuning per container or shortcut so one game’s optimization cannot destabilize others.
Measure shader compilation stutter, memory use, and performance after extended play. Avoid increasing GPU heap limits or disabling synchronization globally without evidence that it helps and remains stable.
Run a short compatibility suite after every driver or renderer update, including launch, gameplay, resolution changes, suspend/resume, and repeated launches.
4. Release and recovery
Ship driver changes and rootfs/Wine changes as separate, reversible units where possible.
Test upgrade and rollback using copied containers first; verify user containers and shortcuts remain intact.
Publish the tested device/GPU, driver versions, settings, known issues, and backup/restore instructions with the update.
Roll out experimental driver defaults only after stability and performance results show a clear benefit; otherwise leave the current default unchanged.
Suggested order: implement backups and staged rootfs installation first; add driver diagnostics and integrity checks next; then benchmark driver and per-game tuning on the Snapdragon 8 Elite before changing defaults. I found no app/src/test or app/src/androidTest directories in the checked-out tree, so this plan includes adding validation around the riskiest migration and recovery paths.

Hide mouse in android system, when external mouse and keyboard connected and sandbox running.
